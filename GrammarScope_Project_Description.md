# GrammarScope — Project Description

## 1. Project Title

**GrammarScope: Interactive Syntax Tree Generator and Grammar Ambiguity Analyzer**

## 2. Abstract

GrammarScope is an educational full-stack web application designed to help students, developers, and instructors explore context-free grammars (CFGs), generate concrete parse trees, and investigate ambiguity in formal languages and compiler design. Users can enter an arbitrary context-free grammar and an input string, validate the grammar, determine whether the string belongs to the language, inspect full interactive syntax trees, and detect whether multiple distinct derivations exist for that string.

For ambiguous grammars, GrammarScope provides concrete side-by-side derivation trees proving ambiguity. The application couples compiler theory, general context-free parsing algorithms (Earley parser with Shared Packed Parse Forest), evidence-based ambiguity analysis, and an interactive React-based visual interface into a single learning platform.

## 3. Problem Statement

Students studying compiler design and formal languages often struggle to visualize how context-free grammars derive strings, how derivation steps correspond to tree hierarchies, and how ambiguity arises when one string yields multiple distinct parse trees. Manual derivation and tree drawing are tedious and error-prone, especially for recursive grammars, precedence rules, and expressions.

GrammarScope solves this problem by providing an interactive visual workbench to define CFGs, test arbitrary expressions, render concrete parse trees, inspect applied production rules, and demonstrate ambiguity through direct visual comparison of alternative trees.

## 4. Objectives

- Allow users to enter, edit, and validate arbitrary context-free grammars.
- Automatically identify terminals, nonterminals, productions, start symbol, and nullable symbols.
- Determine whether an input string belongs to the language generated by the grammar.
- Generate concrete, full-height parse trees from actual general parsing algorithms (not hardcoded mockups).
- Detect string-level ambiguity by determining whether two or more distinct parse trees exist.
- Compare alternative parse trees visually side-by-side.
- Accurately categorize results as confirmed ambiguous, unique parse, or string rejected.
- Provide responsive, interactive tree manipulation (zoom, pan, fit to screen, and clickable node inspector).
- Provide pre-configured textbook presets (e.g., Ambiguous Arithmetic, Operator Precedence, Dangling Else, Balanced Parentheses, Left Recursion).

## 5. Scope and Implemented Features

### 1. Interactive Multi-Tab Interface
The application is organized into focused, interactive tabs:
- **Syntax Tree Generator**: Primary workspace to enter grammar rules and input strings, view ambiguity verdicts, and explore interactive syntax trees.
- **Ambiguity Analyzer**: Dedicated view for side-by-side comparison of alternative derivation trees for ambiguous expressions.
- **Grammar Editor & Validator**: Multiline grammar input with live validation, start-symbol selection, symbol breakdown (terminals, nonterminals, nullable symbols), and syntax diagnostics.
- **Presets & Guide**: 1-click loading of classic textbook grammars with theoretical explanations of key compiler concepts.

### 2. General Context-Free Parsing Engine (Earley Algorithm)
- Uses an Earley chart parser capable of handling arbitrary CFGs, including:
  - Direct and indirect left recursion (e.g. `S -> S a | b`).
  - Epsilon productions (`ε`, `epsilon`, or empty RHS).
  - Ambiguous grammars with overlapping derivations.
- Retains alternative derivations through a cycle-aware Shared Packed Parse Forest (SPPF) rather than a simple boolean recognizer.
- Canonical tree signature algorithm prevents duplicate counting of identical derivations.

### 3. Evidence-Based Ambiguity Detection
- Evaluates the parse forest for an input string.
- If two or more structurally distinct parse trees are extracted, ambiguity is **confirmed** with concrete visual evidence (Tree 1 and Tree 2 rendered side-by-side).
- If exhaustive analysis completes with exactly one derivation, **unique parse** is confirmed.
- If the string cannot be derived, a clear **no parse** result is reported.

### 4. Interactive Syntax Tree Visualization (D3.js)
- Responsive SVG tree rendering powered by D3.js.
- Clean color distinction: nonterminals (indigo circles), terminals (emerald rounded rectangles), and epsilon (amber dashed boxes).
- Smooth interactive pan and zoom controls (Zoom In, Zoom Out, Fit to Screen, Reset View).
- **Clickable Node Inspector**: Clicking any node opens a floating detail card showing the symbol name, node type (nonterminal/terminal/epsilon), applied production rule, and covered token span.
- Top-anchored layout (`translateY = 55px`) with dynamic proportional scaling prevents bottom leaf node cut-offs and eliminates unwanted white shades.

## 7. High-Level Workflow

```text
User Input (Grammar + Expression)
              │
              ▼
   FastAPI Backend Validation
              │
              ▼
  Earley Recognition & Chart Processing
              │
              ▼
 Shared Packed Parse Forest (SPPF) Construction
              │
              ▼
     Extract Distinct Trees & Canonicalize
              │
              ▼
 Ambiguity Classification (Ambiguous / Unique / Rejected)
              │
              ▼
 React Frontend + D3.js Interactive Visualization
```

1. The user defines a CFG (or selects a textbook preset) and provides an input string.
2. The grammar parser parses productions and identifies terminals and nonterminals.
3. The Earley parser runs prediction, scanning, and completion across input tokens.
4. An SPPF is constructed retaining all valid derivation paths.
5. Distinct parse trees are extracted and compared via canonical structural signatures.
6. The frontend renders the status badge and displays the full interactive D3 parse tree (or side-by-side trees if ambiguous).

## 8. Result Categories

| Result | Meaning | Visual Indication |
|---|---|---|
| **Ambiguity confirmed** | At least two distinct valid parse trees were extracted for the same string | Rose banner (`⚠️ AMBIGUOUS: Found 2 Distinct Trees`) + Side-by-side trees |
| **Unique parse confirmed** | The parse forest search completed exhaustively and established exactly one tree | Emerald banner (`✅ UNAMBIGUOUS: Exactly 1 Unique Tree`) + Single tree |
| **No parse** | The input string cannot be derived from the grammar | Slate banner (`❌ String Cannot Be Derived`) |
| **Inconclusive** | Resource limits or infinite cycle prevented complete enumeration | Purple banner (`❓ Inconclusive`) |

## 9. Example Use Cases Demonstrated

### 1. Ambiguous Arithmetic Grammar
- **Grammar:** `E -> E + E | E * E | ( E ) | id`
- **Input:** `id + id * id`
- **Result:** Ambiguity Confirmed. Two distinct parse trees are generated:
  - Derivation A: `(id + id) * id` (addition evaluated first)
  - Derivation B: `id + (id * id)` (multiplication evaluated first)

### 2. Unambiguous Precedence Grammar
- **Grammar:**
  ```text
  E -> E + T | T
  T -> T * F | F
  F -> ( E ) | id
  ```
- **Input:** `id + id * id`
- **Result:** Unique Parse Confirmed. Exactly one syntax tree is derived, enforcing multiplication precedence.

### 3. Dangling Else Ambiguity
- **Grammar:** `S -> if c then S else S | if c then S | stmt`
- **Input:** `if c then if c then stmt else stmt`
- **Result:** Ambiguity Confirmed. Illustrates the classic compiler problem of which `if` binds the `else` clause.

## 10. Theoretical Limitations

- **General Ambiguity Undecidability:** Determining whether an arbitrary context-free grammar is ambiguous is undecidable (proven by reduction from Post's Correspondence Problem). GrammarScope provides evidence-based ambiguity verification on given strings.
- **Cycle Handling:** Grammars containing derivation loops (e.g. `A -> A` or nullable cycles) are cycle-detected during forest extraction to guarantee termination.

## 11. Verification and Testing

The backend is backed by an automated test suite (`pytest`) comprising 26 tests covering:
- Valid and invalid grammar syntax parsing.
- Epsilon representation and alternative merging.
- Unreachable and non-productive symbol detection.
- Whitespace and maximal-munch compact tokenization.
- Earley parsing across left recursion, nested parentheses, and epsilon rules.
- Ambiguity confirmation with distinct parse tree comparisons.
- FastAPI REST endpoints, schemas, and error handlers.

## 12. Conclusion

GrammarScope bridges the gap between abstract compiler theory and practical understanding. Through its general parsing engine, evidence-based ambiguity analysis, and interactive D3 visualization, it provides a tool for learning how context-free grammars derive formal languages.
